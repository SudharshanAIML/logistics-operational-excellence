Process-Level Granularity

Computed per process (unload → sort → stow → pick → pack → load), per zone, per shift. One number a hub manager can compare Monday vs Tuesday, Hub ATL vs Hub LAX.

6 Innovations Beyond the Brief
Core Innovation
Uncertainty-Aware
Staffing Engine
We don't output "you need 42 people." We produce P10/P50/P90 quantile forecasts and solve a newsvendor trade-off — cost of understaffing (SLA penalty, overtime) vs overstaffing (idle labor). Managers choose their own service level from a cost curve.
LightGBM · Quantile Regression · Newsvendor Model
Core Innovation
Digital Twin
What-If Lab
SimPy discrete-event simulation of the full hub. "What if inbound spikes 30% and 5 sorters call in sick?" Simulated dock-to-stock time, backlog accumulation, and SLA breach probability in seconds. Monte Carlo over forecast uncertainty.
SimPy · Monte Carlo Simulation · Discrete-Event
Core Innovation
Prescriptive CP-SAT
Roster Optimizer
OR-Tools CP-SAT generates a publishable shift roster, not just a headcount number. Respects skills matrix, max consecutive hours, rest rules (min 11h), cross-training eligibility, and labor law limits. Output is a Gantt board ready to post.
OR-Tools CP-SAT · Constraint Satisfaction · Gantt Board

Architectural Guarantee — Problem Statement Note
Privacy Built
Into the Foundation
The problem statement specifies: "This tool is not intended to measure or evaluate individual employee productivity." We treat this as an architectural requirement, not a display guideline.

🛡 Aggregation Floor — N ≥ 5

Every OEI metric, throughput ratio, quality ratio, and utilization ratio is hardcoded to null if derived from fewer than 5 active workers in any zone/shift/process slice. No individual worker can ever be inferred from any metric shown on this platform.

N≥5
Minimum active workers required
before any efficiency metric is shown.
Fewer than 5 → all values redacted.
Configurable via Admin panel. Compatible with GDPR Article 89 aggregation principles and enterprise HR data governance requirements.
