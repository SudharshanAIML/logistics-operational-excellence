Architectural Guarantee — Page 2 Note
Most Teams
Will Miss This
The problem statement note is explicit: "This tool is not intended to measure or evaluate individual employee productivity." This is not a footnote — it is a judge test.

🛡 Aggregation Floor Guarantee — N = 5

Every OEI metric, throughput ratio, quality ratio, and utilization ratio is hardcoded to be redacted if derived from fewer than 5 active workers in any zone/shift/process slice. No individual can be profiled. This is enforced at the API response layer — not just the UI.

N≥5
Minimum active workers required
before any metric is displayed.
All others return null.
Configurable via Admin panel. Compliant with GDPR Article 89 aggregation requirements and enterprise HR data governance standards.
